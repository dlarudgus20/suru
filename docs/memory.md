## 최근 변경 사항 (2026-02)
- `libsuru-vm`에 upvalue 실행 경로가 추가되었고, C 함수에서도 `VM::getupvalue()`로 접근할 수 있다.
- C 함수 시그니처는 `void (*)(VM* vm)`로 단순화되었다.
- bool 전용 논리 opcode `AND`, `OR`가 추가되었다.
- 표준 함수 `div(a, b)`가 추가되었고 `(몫, 나머지)`를 다중 반환한다.
- 바이트코드 예제 테스트:
  - `tests/upvalue.sura`
  - `tests/div.sura`
